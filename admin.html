Backup ও Restore

Backup ফাইলে ব্যক্তিগত ফোন নম্বরসহ সংবেদনশীল তথ্য থাকে। নিরাপদ স্থানে রাখুন এবং কারও সঙ্গে প্রকাশ্যে শেয়ার করবেন না।

Backup তৈরি

বর্তমান সব রক্তদাতার তথ্য JSON ফাইলে সংরক্ষণ করুন।

Backup Restore

শুধু Owner পুরোনো JSON backup থেকে তথ্য পুনরুদ্ধার করতে পারবেন। একই ID থাকলে তথ্য প্রতিস্থাপিত হবে।

Admin ব্যবস্থাপনা

সর্বোচ্চ ২ জন সাধারণ Admin। প্রথমে প্রত্যেক Admin-কে Google দিয়ে এই প্যানেলে একবার প্রবেশ করে Firebase UID নিতে হবে। তারপর Owner এখানে UID ও Gmail যোগ করবেন।

নিরাপত্তা ও অনুমতি

বর্তমান প্রবেশাধিকার

  • সাধারণ Admin: রক্তদাতার তথ্য দেখা ও সংশোধন।
  • সাধারণ Admin: রক্তদাতা মুছে ফেলতে পারবে না।
  • Owner: Admin নিয়ন্ত্রণ, Backup Restore ও রক্তদাতা মুছে ফেলার ক্ষমতা।
  • Google account-এ 2-Step Verification চালু রাখুন।
নিরাপত্তা কার্যকর করতে এই প্যানেলের সঙ্গে দেওয়া Firestore Rules অবশ্যই Firebase Console-এ প্রকাশ করতে হবে। শুধু HTML ফাইল দিয়ে নিরাপত্তা নিশ্চিত হয় না।
